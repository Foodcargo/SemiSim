## 이번 변경

- ProcessSession Capture/Restore: 부모 상태 및 전체 실행 이력을 복원하고 Undo를 유지한다. 잘못된 부모 참조는 교체 전에 차단한다.
- ProcessResult에 실행 당시 typed recipe를 보존하며 JSON discriminator로 제한된 형식만 읽는다.
- 계산 예외는 CalculationError로 기록하고 부분 상태를 커밋하지 않는다.
- WPF 실행을 비동기로 연결하고 취소·실행 중 상태 변경 방지·이전 레시피 결과 표시를 추가했다.
- 세션 저장/열기 버튼, 검사 모드별 대상 ID 필터, 숫자 검사 목표 기본값을 연결했다.
- 세션 JSON 20 MB 제한, null/unknown field/숫자 enum/부모 순환·누락/중복 run 검증, 취소 시 임시 파일 정리 및 기존 저장 파일 보존을 추가했다.
- 설정 로더에 unknown field 및 크기·누락 컬렉션·파일 접근 오류 검증을 추가했다. 이 로더가 전체 공정 실행에 연결됐다는 뜻은 아니다.
- 초기화의 직경 폐쇄 선택지, 두께·농도·영역 폭·오염·초기 산화막·해상도를 공통 검증한다. BareSi에서 비활성 산화막 입력은 무시한다.
- 산화 UI의 NaN/Infinity 및 허용 범위 밖 입력을 차단했다.
- DepositionConditions: CVD/PVD/ALD의 공정 조건으로 막 두께를 계산한다. 비활성 필드는 레시피에서 제외하고 직접 전달되면 거부한다. 지원 재료 조합·PR·평탄 표면·장비 한계·10000 nm 모델 한계를 검사한다.
- 증착 기본 품질 목표는 명세 4.12의 재료별 두께 ±10% 및 ALD purge penalty를 사용한다. 품질 실패도 계산된 상태를 보존한다.
- 기존 DepositionParameters의 직접 두께 경로는 내부 이전 API/테스트용으로 남아 있다. 신규 WPF 증착은 DepositionConditions를 사용한다. 이 경로를 통합하고 이전 레시피를 명시적으로 마이그레이션하는 작업이 남아 있다.
